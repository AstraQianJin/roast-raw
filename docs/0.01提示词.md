## 4. 统计断言策略（关键，来自已验证发现，别逐位死磕）

老 fixture 用**三种不同精度**，分层断言：

- **整数**（周 total / S·B·D main·var / roles）：精确相等。
- **六组「周」weighted**（`capData.items[].w`）：fixture 存**原始浮点**（如 `27.75`、`14.299999999999999`）→ 与引擎**原始值**比，epsilon `1e-9`（实测逐位精确，max diff = 0）。
- **六组「cycle」weighted + tonnage 板**：用 `r1()` = 先 `round(x,4)` 再 Decimal `HALF_UP` → 精确复现 `[148.8,…,170.2]` 与 `139568.0 kg = 139.6 t`（`170.15→170.2`）。
- **16 叶「周」weighted**（`mmData.weeks[].w`）：fixture 是 1dp 裸 `round()` 且累加顺序不同 → **容差 ≤0.1，不要追求逐位精确**。实测 10 处恰好差 0.1，全在 `.x5` 边界（glutes 22.25→22.2、erectors 16.95→16.9、core 14.25→14.2 等），属约定差异，**不是统计 bug**。
- **反向验证**：至少一组 sabotage 注入后断言真变红，证明「全绿」可信。

## 8. 训练与计划规则

- 主项 = Top set + Back-off；热身自动生成但**只作建议**；Deload 减量不减动作。
- 辅项不写重量，只给组数、次数、目标 RPE。
- 变式：8 个固定变式 + 其余按弱点安排。
- 准备度：3 主观（Muscle Fatigue / Neural Arousal / Nutrition）+ 3 客观（HRV / Sleep Score / Resting HR）+ 时段修正；**只建议，永不自动改重量**；缺失项跳过、不按 0 计。
- 达成率：`composite = 0.40*goal + 0.40*bodyweight + 0.20*completion`；`completion = 0.60*main + 0.25*var + 0.15*acc`；可超 100%（capped=false）；goal 只算 S/B/D 等权。
- Test Week 顺序：主项 S/B/D → 一级变式（Power Clean / Low-bar Squat / Wide-grip Bench / Sumo Deadlift）→ 二级变式（OHP / Weighted Pull-Up / Weighted Dip / Barbell Row）→ 5 km。
- 比赛模式：Test Week = 比赛周，赛前 Taper，只测 S/B/D，三把建议 92% / 97% / 102%。
- 非比赛：从 S/B/D、一级、二级、5 km 中选 1–4 组，日期随意、只记录。
