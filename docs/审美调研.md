## 4 · 周期与容量可视化对照

### 4.1 周期条
- 老 App：周轨＝逐周胶囊按钮，按 cycleType 着色（template.html:13126–13127 `ct-`+类型；CSS 596 行起），当前周反色 `.on`，自动 scrollIntoView 居中；deload 单独绿色。样张 old-ref-app-today-ex.png 顶部 W1–W9 红/绿/蓝/紫胶囊。
- 老站计划页：编号周块轨 + 阶段图例（TRAINING/TEST/VOLUME DELOAD/CURRENT）+ 「12 WEEKS LEFT」计数；块段按阶段分色带名称。
- 新现状：灰块一排、仅当前周红、虚线分隔，无阶段名/周数（用户截图指出）。
- 0.10 方向：合并两者——分段色带（阶段色+软底）标阶段名与周数范围，段内逐周小格可点，当前周反色；deload 绿；其他出现 Block 的位置（Plan 头、Analysis 周选择、Review）共用同一组件与令牌。

### 4.2 MEV/MRV 容量条
- 老 App `.mb-*`（template.html:3224–3266）：整块折叠按钮默认收起一行（44px head）；展开后每肌群行 grid 60px/1fr/58px；track 16px 高 inset 底；**区间带** `.mb-band`（MEV–MRV 参考带，虚线边）；**刻度** `.mb-tick`（MEV/MAV/MRV 竖线，mrv 更实）；fill 按 SBD 三色；分摊量用 135° 斜纹 `.mb-assoc`；右侧 mono 数值+小字单位；底部图例含斜纹/零组圆点。不做越界红绿判定（3223 行注释）。
- 老站计划页：每举一行「MEV 8 / MEV 18」区间文字 + 横条 + RANGE 标注；另有 WORKING SETS 柱状按周。
- 新现状：Analysis 有容量数字与肌群热图，但 MEV/MRV 不可视化（用户原话）。
- 0.10 方向：Analysis 容量行升级为 track+band+ticks+fill+斜纹分摊+图例；**Analysis 内默认展开**（用户要看得见），Today 侧保持折叠一行； landmark 数值来源沿用现有 stats 契约，不新造科学口径；保留「参考标记不做红绿判定」。

### 4.3 数据张力器件（老站/老 App 共有）
- 硬偏移卡影 4px 4px 0（ex）；暗色对应软影但保留 1px 墨边。
- 发丝网格：gap:1px + background:var(--line) 做分格（hub:302/381/388），事实条 4 格大数字。
- mono eyebrow 大写小字 + serif 大标题 + 正文小字的三层对比。
- 选中块反色、胶囊渐变底（--pill-grad）、印刷感只落三处（template.html:321 注释）。
