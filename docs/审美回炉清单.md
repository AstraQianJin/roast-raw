# 审美回炉清单（0.10 建立，0.11–0.12 执行）

依据：[审美调研](审美调研.md)（0.09 老网页全面调研）与用户 2026-11-14 裁定。本清单是逐项验收依据；每项写明改哪里、改成什么样、怎么算完成。易变数值（版本、断言数）不写死，去源文件查。

## 总裁定（不再重问）

- Light = 老 App 默认 ex 暖纸色；Dark 保持现配色不动色相，只补齐派生 token。落地页可用站点 ex 纸色 + 颗粒，属 0.11。
- 字体：Georgia衬线展示体（老站「花体」）+ 系统无衬线正文 + 等宽数字；零网络字体下载。
- 视觉语言：数据页编辑风（大数字、细线网格、纸面、硬投影卡片），操作页（表单/编辑器）保持清晰卡片。
- 导航：顶栏四项 PLAN / ANALYSIS / ARCHIVE / OUTLOOK 单行；Settings 收进顶栏齿轮图标，`/settings` 深链保留；主题为紧凑 L/D 段控件。
- 周期六色（hyper/strength/transmute/peak/custom/deload）进 tokens，双主题各一套，所有出现 Block/周期的地方统一用色。
- 不引入任何运行时 UI/图表/动画框架；动效只用 CSS + 已有 Motion One，且尊重 prefers-reduced-motion。
