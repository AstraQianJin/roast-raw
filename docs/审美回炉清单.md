# 审美回炉清单（0.10 建立，0.11–0.12 执行，0.15 起全量复用老 App 语言）

依据：[审美调研](审美调研.md)（0.09 老网页全面调研）与用户 2026-11-14 裁定。本清单是逐项验收依据；每项写明改哪里、改成什么样、怎么算完成。易变数值（版本、断言数）不写死，去源文件查。

## 总裁定（不再重问）

- **2026-11-14 最高裁定**：除动作页杠铃负荷 UI 与肌群图外，所有页面所有 UI 完全复用老 App / 老站视觉语言，不允许新的装饰性巧思。App 页用老 App 语言；落地页保留 0.11 移植的发布页风格。
- Light = 老 App 默认 ex 暖纸色；Dark = 老 dark 配色。主题切换为顶栏紧凑 L/D 段控件。
- 字体：老站展示体 + 清晰正文 + 等宽数字；零网络字体下载（canvas 分享卡同用本地字体栈）。
- 视觉语言：数据页编辑风（大数字、细线网格、纸面、硬投影卡片），操作页（表单/编辑器）保持清晰卡片。
- 导航：顶栏四项 PLAN / ANALYSIS / ARCHIVE / OUTLOOK 单行；Settings 收进顶栏齿轮图标，`/settings` 深链保留。
- 周期六色（hyper/strength/transmute/peak/custom/deload）进 tokens，双主题各一套，所有出现 Block/周期的地方统一用色。
- 不引入任何运行时 UI/图表/动画框架；动效只用 CSS + 已有 Motion One，且尊重 prefers-reduced-motion。
- **审查口径（2026-11-14 裁定）**：推进到 0.20 期间不设外部审查暂停；由实现会话自审 + 回归断言 + 四宽双主题截图点名位置，用户终审集中在 0.20 预览验收。
