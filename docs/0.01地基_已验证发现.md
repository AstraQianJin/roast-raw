## 3. 关键坑：weighted 的「精度 / 取整约定」按 fixture 分层（最重要）

老 fixture 不是同一种取整。逐位追求精确会白烧一轮 token。实测结论：

| 量 | fixture 存法 | 断言策略 |
|---|---|---|
| 周 total / S·B·D / roles | 整数 | 精确相等 |
| 六组 **周** weighted（`capData.items[].w`） | **原始浮点**（如 `27.75`、`14.299999999999999`） | 与引擎**原始值**比，epsilon `1e-9` → 实测 **max diff = 0.000000000000，逐位精确** |
| 六组 **cycle** weighted（spec 目标 `148.8…170.2`） | 1dp，**Decimal half-up** | 用 `r1()` = 先 `round(x,4)` 再 `HALF_UP` → 精确（`170.15→170.2`） |
| 16 叶 **周** weighted（`mmData.weeks[].w`） | 1dp，**Python `round()` half-even + 不同累加顺序** | **容差 ≤0.1**（spec 原文「weighted 每周每叶误差 ≤0.1」）；实测 10 处恰好 0.1，全在 `.x5` 边界 |
| cycle tonnage | `139568.0 kg` | 精确；口径 = resolver `mround(0.5/2.5)` 后逐段 top/back-off 负荷 × 组 × 次 |

要点：

- **显示 / 看板取整用 `r1()`（4dp 预清洗 + Decimal HALF_UP）**：能精确复现 cycle 六组目标与 139.6 t 容量板。`r1` 先 `round(x,4)` 清掉浮点噪声再 half-up，所以 `170.14999999999998 → 170.15 → 170.2`。
- **16 叶周 weighted 不要追求逐位精确**：`mmData` 用裸 `round()` 且累加顺序与「逐行 sets×coef」不同，`.x5` 边界会差 0.1。残留 10 处全部 = 0.1，属约定差异，**不是统计 bug**：
  `W1 glutes 22.25→22.2`、`W2/W3/W5/W6/W7 erectors 16.95/16.85/17.05→16.9/16.8/17.0`、`W3 glutes 23.25→23.2`、`W9/W10/W11 core 14.25/13.45→14.2/13.4`。
- `mmData.json`、`capData.json` 带 **UTF-8 BOM** → 用 `utf-8-sig` 读，否则 `json.load` 直接报错。

## 4. 统计口径（已落地、可复用）

- bucket 顺序 `main → sbdVar → nonSbdVar → accessory`；`_is_power_clean` = 名在 `POWER_CLEAN_NAMES` 或 `cat=="D.Vari.Power"`，排除 `SNATCH_NAMES`。
- 16 叶 weighted = `Σ sets×coef`；direct = 只在 **primary** 叶计 sets，primary = `coef ≥ 0.8×max`（secondary `≥0.3×max`，epsilon `1e-9`）。
- 六组 coef = 叶向量在 `group_leaves` 上的 **max 折叠（绝不求和）**；组 direct = 每行按折叠组计一次 sets。
- `group_leaves`：chest=[chest]；shoulders=[delts_ant,delts_lat,delts_post]；back=[upper_back,erectors,lats]；legs=[quads,hamstrings,glutes,adductors]；arms=[triceps,biceps]；abs=[core]；额外叶 forearms/calves。
- `mround(x,step)=round(x/step+1e-9)*step`；`row_load`：main 0.5kg、variation 2.5kg、accessory None；`disp_load=mround(anchor×pct,0.5)`，`ANCHOR_CATEGORY {S.Main→sq_1rm, B.Main→bp_1rm, D.Main→dl_1rm}`。
- 周数 / deload / test 全由 `blocks` 推（work+deload 跨度；test = `cycleType "Peak"` 或 `workMode "Top.Test"`）；日期 = `start+(w−1)*7+weekday_offset`。
- 处方正则（`_TOP_RX/_TOP_RX_EN/_BASE_RX/_SIDE_RX/_PCT_RX/_KG_RX/_KG_AT/_CAL_PREFIX`）逐字移植；`sets` = 各段组数之和（265 行全部校验通过）。
