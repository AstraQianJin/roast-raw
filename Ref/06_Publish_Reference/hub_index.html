02 / One switch

One ledger, two densities.

By default the lift, the load, the sets × reps and a three-tier effort label stay in view — legible at the rack. Press the switch in the top bar and the same card opens set-by-set actuals, notes and the rest timer — complete at review. The same switch exists in the app and on this site: flipping it changes nothing in the ledger and never discards a half-typed set.

One tap in the top bar — the same day card changes in place.

  • Nothing is deleted — the entry layer only folds; a half-typed set is still there when you switch back.

  • Nothing navigates — no navigation, no reload, no extra sheet, and your scroll position holds.

  • The web gets the same switch — the site's day page carries the same state: readable at the rack, recordable at review.

05 / Capabilities

Six things, from plan to review.

Every item works offline. The network is used only by the optional AI and cloud features you turn on.

01

Cycle plan

13-week blocks with weekly prescriptions and volume. Plans import, export and archive; a broken import is rejected before it touches your log.

02

Daily prescription

Main lifts, variations and accessories list sets, intensity and load row by row — no spreadsheet to cross-check.

03

Plate math

Six equipment types resolve to real pin positions or plate stacks, so barbells, pin machines and dumbbells all land on a usable load.

04

Set-by-set logging

Check-offs, rest timer and the daily summary share one screen. There is no upload step.

05

Trends & volume

e1RM trends plus weekly volume completion and distribution, straight from your own log.

06

Export & share

CSV, XLSX, JSON and JSONL exports open in any spreadsheet, and imports use the same fields — a round trip comes back unchanged.
